# OXM OS 🌐

**OXM OS** is a web-based operating system clone designed to deliver a seamless desktop-like experience directly in your browser. Built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**, OXM OS showcases how modern web technologies can replicate complex desktop environments.

## 🚀 Features

1. **Desktop Environment:**
   - Drag-and-drop desktop icons with persistence.
   - Dynamic wallpaper customization.
   - Responsive layout that mimics the look and feel of popular operating systems.
   - Blend desktop elements from Windows, macOS, Linux as well as orignal OXM OS elements.

2. **Taskbar and Widgets:**
   - A fully functional **taskbar** with system icons.
   - Widgets for quick access to essential tools.
   - Start Menu for navigating the app ecosystem.

3. **Integrated Apps:**
   OXM OS includes several pre-built apps:
   - **File Explorer:** Browse a simulated file system.
   - **Video Player:** Play videos seamlessly.
   - **Gallery & Camera:** View and capture images.
   - **Music Player & Voice Recorder:** Enjoy audio and record your voice.
   - **Terminal:** Execute basic commands in a simulated terminal.
   - **Calculator:** Perform quick calculations.
   - **Settings:** Customize your OXM OS experience.

4. **Customizability:**
   - Global state management enables easy personalization.
   - Change wallpapers, themes, and more with ease.

5. **Future Plans:**
   - Backend integration for enhanced functionality.
   - Performance optimizations for faster load times.
   - Expanding app functionality to make them fully interactive.

## 🛠️ Tech Stack

- **Frontend Framework:** [Next.js 14](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** TypeScript
- **UI Components:** [ShadCN](https://shadcn.dev/)

## 📥 Installation

1. Clone the repository:
   ```bash
   https://github.com/Mr-oxm/os-app
   ```
2. Navigate to the project directory:
   ```bash
   cd oxm-os
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```
